# Pasientvennlige radiologirapporter med LLM

Workshopmateriell om hvordan språkmodeller kan brukes til å skrive om radiologirapporter til pasientvennlig språk. Deltakerne prøver selv og ser hvordan ulike instruksjoner endrer svaret fra modellen.

Åpne notatboken i Google Colab. Du trenger bare en nettleser og en Google-konto, ingen installasjon.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/skaliy/patient-friendly-llm/blob/main/workshop.ipynb)
