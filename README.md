# Pasientvennlige radiologirapporter med LLM

Workshopmateriell om hvordan språkmodeller kan brukes til å skrive om radiologirapporter til pasientvennlig språk. Deltakerne prøver selv og ser hvordan ulike instruksjoner endrer svaret fra modellen.

Åpne notatboken i Google Colab. Du trenger bare en nettleser og en Google-konto, ingen installasjon.

## English

Workshop material on how language models can rewrite radiology reports into patient-friendly language. Participants try it themselves and see how different instructions change the model's answer.

The reports, prompts and model answers are in Norwegian, since the task is Norwegian. The explanations in this version of the notebook are in English. If you do not read Norwegian, work in a group with someone who does.

Open the notebook in Google Colab. You only need a browser and a Google account, no installation.
